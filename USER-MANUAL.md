# GoreeCloud Cast — User Manual

Version: v0.1  
Status: Development

There is no end-user Cast application or receiver available from this repository yet. Phase 0 currently provides only internal core contracts and tests. No documented user workflow should be interpreted as an implemented feature.

Planned interaction concepts such as **Cast**, **Now Casting**, **Continue on…**, receiver selection, guest casting, mirroring, multi-room audio, and remote casting remain roadmap items until implementation and verification evidence exists.
